Question 1: Handle Division by Zero

Problem Statement

Write a Java program to read two integers and divide the first number by the second number.
If the second number is zero, handle the  ArithmeticException  and display an appropriate message.

Sample Input

20
5

Sample Output

Result = 4

Sample Input

20
0

Sample Output

Cannot divide by zero

Approach

1.  Read two integers.

2.  Place the division operation inside  try .

3.  Handle  ArithmeticException  using  catch .

4.  Display the result if no exception occurs.

Full Running Java Code

import java.util.Scanner;

public class Main
{
    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);

        int a = sc.nextInt();
        int b = sc.nextInt();

        try
        {
            int result = a / b;

            System.out.println("Result = " + result);
        }
        catch(ArithmeticException e)
        {
            System.out.println("Cannot divide by zero");
        }
    }
}

Question 2: Handle Invalid Array Index

Problem Statement

Given an array of integers and an index, print the element at that index.

If the index is invalid, handle the exception and print:

Invalid Index

Sample Input

5
10 20 30 40 50
2

Sample Output

Element = 30

Sample Input

5
10 20 30 40 50
7

Sample Output

Invalid Index

Approach

The valid indexes of an array of size  5  are:

0 1 2 3 4

Accessing index  7  causes  ArrayIndexOutOfBoundsException .

Full Running Java Code

import java.util.Scanner;

public class Main
{
    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        int[] arr = new int[n];

        for(int i = 0; i < n; i++)
        {
            arr[i] = sc.nextInt();
        }

        int index = sc.nextInt();

        try
        {
            System.out.println("Element = " + arr[index]);
        }
        catch(ArrayIndexOutOfBoundsException e)
        {
            System.out.println("Invalid Index");
        }
    }
}

Question 5: Multiple Exceptions

Problem Statement

Write a program that can handle both:

Division by zero

Invalid array index

Use multiple  catch  blocks.

Sample Input

10
0

Sample Output

Cannot divide by zero

Full Running Java Code

import java.util.Scanner;

public class Main
{
    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);

        int[] arr = {10, 20, 30};

        int choice = sc.nextInt();

        try
        {
            if(choice == 1)
            {
                int result = 10 / 0;

                System.out.println(result);
            }
            else
            {
                System.out.println(arr[5]);
            }
        }
        catch(ArithmeticException e)
        {
            System.out.println("Cannot divide by zero");
        }
        catch(ArrayIndexOutOfBoundsException e)
        {
            System.out.println("Invalid Array Index");
        }
    }
}

Question 7: Validate Age Using throw

Problem Statement

Write a program that reads a person's age.

Otherwise print:

Eligible

Sample Input

21

Sample Output

Eligible

Sample Input

15

Sample Output

Not Eligible

Approach

The exception is not generated automatically by Java.

The program explicitly generates it using:

throw new IllegalArgumentException();

Full Running Java Code

import java.util.Scanner;

public class Main
{
    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);

        int age = sc.nextInt();

        try
        {
            if(age < 18)
            {
                throw new IllegalArgumentException();
            }

            System.out.println("Eligible");
        }
        catch(IllegalArgumentException e)
        {
            System.out.println("Not Eligible");
        }
    }
}

Question 10: Exception Propagation

Problem Statement

Create three methods:

method1()
method2()
method3()

Generate an exception inside  method3() .
Allow it to propagate to  main()  and handle it there.

Sample Output

Exception handled in main

Full Running Java Code

public class Main
{
    static void method3()
    {
        int result = 10 / 0;

        System.out.println(result);
    }

    static void method2()
    {
        method3();
    }

    static void method1()
    {
        method2();
    }

    public static void main(String[] args)
    {
        try
        {
            method1();
        }
        catch(ArithmeticException e)
        {
            System.out.println("Exception handled in main");
        }
    }
}

Question 11: Validate a Number Using throw

Problem Statement

Read a number.
If the number is negative, throw an  IllegalArgumentException .
Otherwise calculate its square.

Sample Input

5

Sample Output

Square = 25

Sample Input

-5

Sample Output

Number cannot be negative

Full Running Java Code

import java.util.Scanner;

public class Main
{
    static int square(int number)
    {
        if(number < 0)
        {
            throw new IllegalArgumentException(
                "Number cannot be negative"
            );
        }

        return number * number;
    }

    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);

        int number = sc.nextInt();

        try
        {
            System.out.println("Square = " + square(number));
        }
        catch(IllegalArgumentException e)
        {
            System.out.println(e.getMessage());
        }
    }
}

Question 16: Medium — Validate Array Index

Problem Statement

Create a method  getElement()  that accepts an array and an index.
If the index is invalid, explicitly throw an  IllegalArgumentException .
Otherwise return the element.

Sample Input

5
10 20 30 40 50
3

Sample Output

Element = 40

Sample Input

5
10 20 30 40 50
8

Sample Output

Invalid Index

Full Running Java Code

import java.util.Scanner;

public class Main
{
    static int getElement(int[] arr, int index)
    {
        if(index < 0 || index >= arr.length)
        {
            throw new IllegalArgumentException(
                "Invalid Index"
            );
        }

        return arr[index];
    }

    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        int[] arr = new int[n];

        for(int i = 0; i < n; i++)
        {
            arr[i] = sc.nextInt();
        }

        int index = sc.nextInt();

        try
        {
            int value = getElement(arr, index);

            System.out.println("Element = " + value);
        }
        catch(IllegalArgumentException e)
        {
            System.out.println(e.getMessage());
        }
    }
}
