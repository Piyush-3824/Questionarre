Question 1 — Safe Division for a Score Calculator

Problem Statement

A score-analysis program receives two integer values and calculates the quotient of the first value divided by the second.

If the operation is valid, display the quotient.

If the divisor is zero, the program should handle the error and display:

Invalid Division

Implement the solution using Java exception handling.

Approach

Read two integers.

Place the division operation inside a  try  block.

Catch  ArithmeticException .

Print the result for valid input.

Print the required error message when the divisor is zero.

Full Java Running Code

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int a = sc.nextInt();
        int b = sc.nextInt();

        try {
            System.out.println(a / b);
        } catch (ArithmeticException e) {
            System.out.println("Invalid Division");
        }

        sc.close();
    }
}

Explanation

Integer division by zero causes an  ArithmeticException .
For example:

20 / 5

produces:

4

whereas:

20 / 0

causes the exception.

The  catch  block prevents abnormal program termination.

Explanation

The  throw  keyword is explicitly tested in the collection.

Problem Statement

Create a method:

static int findAverage(int total, int students)

The method should calculate:

total / students

Do not handle the arithmetic exception inside this method. Instead, declare that the method can throw the exception.
Handle the exception in  main()  and print:

Approach

Catch the exception from  main() .

Full Java Running Code

import java.util.Scanner;

    static int findAverage(int total, int students)
            throws ArithmeticException {

        return total / students;
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int total = sc.nextInt();
        int students = sc.nextInt();

        try {
            System.out.println(findAverage(total, students));

Explanation

The method contains:

throws ArithmeticException

This indicates that the method can allow the exception to propagate to its caller.

Question 7 — Create a Custom Exception for Invalid Temperature

Problem Statement

A weather application accepts a temperature value in Celsius.
Temperatures below  -90  or above  60  are considered invalid.
Create a user-defined exception named:

TemperatureException

For invalid input, print:

For valid input, print:

Approach

1.  Create  TemperatureException  by extending  Exception .

2.  Create a validation method.

3.  Throw the custom exception when the value is outside the permitted range.

4.  Handle it in  main() .

Full Java Running Code

import java.util.Scanner;

class TemperatureException extends Exception {

    public TemperatureException() {
        super("Invalid Temperature");
    }
}

public class Main {

    static void validateTemperature(int temperature)
            throws TemperatureException {

        if (temperature < -90 || temperature > 60) {
            throw new TemperatureException();
        }
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int temperature = sc.nextInt();

        try {

            validateTemperature(temperature);
            System.out.println("Temperature Accepted");

        } catch (TemperatureException e) {
            System.out.println(e.getMessage());
        }

        sc.close();
    }
}

Explanation

The custom exception is created using:

class TemperatureException extends Exception

The validation method throws it when required:

This establishes the basic pattern required for user-defined exceptions.

Question 10 — Password Validation with Custom Exception

Problem Statement

A website requires every password to satisfy these conditions:

1.  At least  7  characters.

2.  At least one digit.

3.  At least one uppercase letter.

Create a custom exception named  PasswordRuleException .
If the password violates any rule, throw the exception and print:

Invalid Password

Otherwise print:

Password Accepted

Approach

Traverse the password character by character.

Track whether a digit and uppercase character are present.

Check the length requirement.

Throw  PasswordRuleException  if any condition fails.

Handle it using  try-catch .

Full Java Running Code

import java.util.Scanner;

class PasswordRuleException extends Exception {

    public PasswordRuleException() {
        super("Invalid Password");
    }
}

public class Main {

    static void validatePassword(String password)
            throws PasswordRuleException {

        boolean hasDigit = false;
        boolean hasUpper = false;

        for (int i = 0; i < password.length(); i++) {

            char ch = password.charAt(i);

            if (Character.isDigit(ch)) {
                hasDigit = true;
            }

            if (Character.isUpperCase(ch)) {
                hasUpper = true;
            }
        }

        if (password.length() < 7 || !hasDigit || !hasUpper) {
            throw new PasswordRuleException();
        }
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        String password = sc.nextLine();

        try {

            validatePassword(password);
            System.out.println("Password Accepted");

        } catch (PasswordRuleException e) {
            System.out.println(e.getMessage());
        }

        sc.close();
    }
}

Question 12 — Custom Exception in a Calculation

Problem Statement

Create a method:

static int calculatePower(int base, int exponent)

The method should calculate  base  raised to  exponent .
The following inputs are invalid:

negative base

negative exponent

For either invalid condition, throw a custom  PowerException  with:

Negative Input

Otherwise return the calculated power.

Approach

Create  PowerException .

Validate both parameters.

Throw the custom exception when either value is negative.

Calculate the power using a loop.

Handle the exception in  main() .

Full Java Running Code

import java.util.Scanner;

class PowerException extends Exception {

    public PowerException() {
        super("Negative Input");
    }
}

public class Main {

    static int calculatePower(int base, int exponent)
            throws PowerException {

        if (base < 0 || exponent < 0) {
            throw new PowerException();
        }

        int result = 1;

        for (int i = 1; i <= exponent; i++) {
            result *= base;
        }

        return result;
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int base = sc.nextInt();
        int exponent = sc.nextInt();

        try {

            System.out.println(
                calculatePower(base, exponent)
            );

        } catch (PowerException e) {

            System.out.println(e.getMessage());
        }

        sc.close();
    }
}

Question 14 — Array Processing with ArithmeticException

Problem Statement

Given an integer array, calculate the sum of all its elements.
For every element  x , calculate:

remaining = total - x

Then determine whether:

remaining % x == 0

Count all elements satisfying the condition.
If an element is zero, the modulo operation will cause an  ArithmeticException .
Do not prevent the exception manually. Allow it to occur and handle it using  catch .

Approach

1.  Calculate the total sum.

2.  Traverse the array.

3.  Calculate the remaining sum.

4.  Apply  % .

5.  If an element is zero, Java generates  ArithmeticException .

6.  Catch the exception and print its standard message.

Full Java Running Code

import java.util.Scanner;

public class Main {

    static void processArray(int[] arr) {

        int total = 0;

        for (int value : arr) {
            total += value;
        }

        int count = 0;

        try {

            for (int value : arr) {

                int remaining = total - value;

                if (remaining % value == 0) {
                    count++;
                }
            }

            System.out.println(count);

        } catch (ArithmeticException e) {

            System.out.println(e);
        }
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        int[] arr = new int[n];

        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        processArray(arr);

        sc.close();
    }
}

Explanation

This is a deliberate preparation question for the more algorithmic exception problem found in the collection.

The critical operation is:

remaining % value

If:

value == 0

Java produces:

java.lang.ArithmeticException: / by zero

The original collection contains this exact conceptual pattern: an array-processing algorithm where a zero element
naturally triggers  ArithmeticException .

Question 15 — Complete Custom Validation System

Problem Statement

A university's scholarship portal assigns a student ID and score to each applicant.

An application is accepted only when:

1.  The student ID contains exactly  7  characters.

2.  The first character is an uppercase letter.

3.  The remaining six characters are digits.

4.  The score is between  40  and  100 .

Create a custom exception named:

ApplicationException

The exception should store an error code.

Use:

101  → invalid student ID

202  → invalid score

For a valid application, print:

Accepted

For an invalid application, print the corresponding error code.

Process multiple applicants.

Approach

1.  Create  ApplicationException .

2.  Store the error code inside the exception.

3.  Create a validation method.

5.  Validate the score.

6.  Throw the appropriate exception code.

import java.util.Scanner;

class ApplicationException extends Exception {

    private int code;

    public ApplicationException(int code) {
        this.code = code;
    }

    public int getCode() {
        return code;
    }
}

public class Main {

    static void validateApplication(
            String studentId,
            int score) throws ApplicationException {

        // Student ID validation
        if (studentId.length() != 7) {
            throw new ApplicationException(101);
        }

        if (!Character.isUpperCase(studentId.charAt(0))) {
            throw new ApplicationException(101);
        }

        for (int i = 1; i < studentId.length(); i++) {

            if (!Character.isDigit(studentId.charAt(i))) {
                throw new ApplicationException(101);
            }
        }

        // Score validation
        if (score < 40 || score > 100) {
            throw new ApplicationException(202);
        }
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int t = sc.nextInt();
        sc.nextLine();

        while (t-- > 0) {

            String studentId = sc.nextLine();
            int score = sc.nextInt();
            sc.nextLine();

            try {

                validateApplication(studentId, score);

                System.out.println("Accepted");

            } catch (ApplicationException e) {

                System.out.println(e.getCode());
            }
        }

        sc.close();
    }
}
